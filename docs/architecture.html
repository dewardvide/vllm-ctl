VRAM guard

weights   = measured weight bytes (else params × bytes per weight) / tensor-parallel
kv/token  = 2 × layers × kv_heads × head_dim × bytes(kv_dtype) / tensor-parallel
total     = weights + kv/token × max_model_len + 1.2 GiB
available = total_vram × gpu_memory_utilization − used − safety_margin
fits      = known and total ≤ available          (unknown never fits)

Lifecycle

Stop sends SIGINT to the process group, then SIGKILL after 20 s. The group is also killed when the parent exits, so engine workers cannot keep holding VRAM. Restart replays the stored executable, arguments, host and port.

Deployment topology

Trust boundaries and risks

The app has no authentication and, as shipped, listens on all interfaces. Do not run it where untrusted hosts can reach the port. -H 127.0.0.1 in the npm scripts and HOSTNAME=127.0.0.1 in the container restrict it to loopback.
